# Fylz Viewer

**Every file is inspectable.** An offline-first web module that can view any file and lightly edit the common
ones. It runs standalone as a PWA and is embedded in the Fylz Android file manager through a WebView.

- No network at runtime — every asset, worker and WASM file is bundled.
- Plugins are lazy-loaded; the initial bundle is core + shell + descriptors (see `npm run build` for the size report).
- Theming: CSS custom properties `--fv-*` only (light/dark), ready to be mapped from Hyle design tokens.

## Capability ladder

| Level | Name | Meaning |
|---|---|---|
| 0 | Identify | Type, size, dates, SHA-256, detected vs claimed type — any file |
| 1 | Raw | Hex view and extracted strings |
| 2 | Structure | Metadata / tree / listing, no faithful render |
| 3 | Render | Faithful read-only view |
| 4 | Light edit | Edit and save a valid file with limited operations |
| 5 | Full edit | Full-fidelity editor (text and code only) |

## Commands

```bash
npm install
npm run dev          # Vite dev server
npm run build        # type-check, static output in dist/ (drop into Android assets), bundle size report
npm test             # Vitest unit tests
npm run test:e2e     # Playwright (needs a prior build; serves dist/ on :4173)
npm run fixtures     # regenerate test/fixtures
```

Before every commit: `npm run build && npm test && npm run test:e2e`.
